Option 2: Check Status (وضعیت سیستم را بررسی کنید)
   ps aux | grep -E "xray|vless_panel"

Option 3: Access Dashboard (داشبورد را باز کنید)
   http://localhost:8888

Option 4: List All Users (لیست تمام کاربران)
   curl http://localhost:8888/api/users | python3 -m json.tool

Option 5: Add New Customer (مشتری جدید اضافه کنید)
   curl -X POST http://localhost:8888/api/user/add \
     -H 'Content-Type: application/json' \
     -d '{"name":"Customer Name","email":"user@example.com","traffic_gb":100}'

Option 6: Get Customer Link (لینک مشتری دریافت کنید)
   curl "http://localhost:8888/api/user/link?email=user@example.com&host=localhost:8443"
